▷ Production Approach · v2 · hybrid · 2026-05-21

One platform. Every show.
Lenses on a single source of truth.

v2 merges the production-first IA (v1) with Peter Kirkup's pitch: lenses shaped to your role, phases that unlock the right tools at the right time, takes for decision branches that don't fork the show, and Aid3n, an AI collaborator that has the whole production in context. Octopus stays the single source of truth for billing & entitlements — the production platform reads from it, never duplicates it.

v1 · production-first IA

9 tabs on a Production Detail

  • Overview / Files / Media / Templates / Team / Hardware / Schedule / Notes / Settings
  • Files live inside a production, not a drive
  • Workspace owns a licence pool · production draws from it
  • Lifecycle existed only on the Schedule tab
  • No AI. No decision branches. No cross-show inventory.
v2 · hybrid w/ Peter's thinking

Lens grid driven by lifecycle phases

  • Lenses replace tabs · same data, different views shaped to role
  • Phases (Pitch → Wrap) unlock lenses + drive billing
  • Takes · run two pathways, commit one, ripple upstream
  • Aid3n · proactive AI with permission boundaries
  • Inventories · workspace-level stock; Octopus owns entitlements
